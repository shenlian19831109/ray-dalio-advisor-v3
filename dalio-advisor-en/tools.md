## Tool 1: Economic Quadrant Assessment

```
┌─────────────────────────────────────────────────────────┐
│           Current Macro Environment Assessment                │
├─────────────────────────────────────────────────────────┤
│                                                          │
│ Step 1: Determine Growth Direction                        │

│  □ Uncertain                                            │
│                                                          │
│ Step 2: Determine Inflation Direction                    │
│  □ Inflation rising (prices up) □ Inflation falling      │
│  □ Uncertain                                            │
│                                                          │
│ Current Quadrant:                                         │
│ □ Quadrant 1: Growth↑ + Inflation↑ → Expansion/early    │
│ □ Quadrant 2: Growth↑ + Inflation↓ → Recovery/mid      │
│ □ Quadrant 3: Growth↓ + Inflation↑ → Stagflation/late   │
│ □ Quadrant 4: Growth↓ + Inflation↓ → Recession         │
│                                                          │
│ Step 3: Allocation Guidance                              │
│ Q1 → Stocks + Commodities + Inflation-linked bonds      │
│ Q2 → Stocks + Long-term bonds                          │
│ Q3 → Gold + Commodities + Inflation protection          │
│ Q4 → Long-term bonds + Defensive stocks (utilities,    │
│        healthcare)                                      │
└─────────────────────────────────────────────────────────┘
```

## Usage Instructions

These tools are designed to **actually apply Dalio's thinking:**

1. Macro investment decision → Tool 1 (Economic Quadrant)
2. Failure/setback → Tool 2 (Pain Reflection)
3. Important decision → Tool 3 (Decision Principles)
4. Team disagreement → Tool 4 (Believability Weighted)
5. Life/career confusion → Tool 5 (Dream + Reality + Determination)

Remember: **Principles aren't meant to be read once—they're meant to be written down and used.**
