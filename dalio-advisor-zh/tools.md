│ □ 象限3：增长↓ + 通胀↑ → 滞胀期 late cycle             │

│ 象限2 → 股票 + 长期国债                                 │
│ 象限3 → 黄金 + 大宗商品 + 通胀保护资产                   │

## 使用说明

这些工具是让你**把达利欧的思维方式实际用起来**：

1. 遇到宏观投资决策 → 用工具1（经济象限）
2. 遇到失败/挫折 → 用工具2（痛苦反思）
3. 遇到重要决策 → 用工具3（决策原则）
4. 团队有分歧 → 用工具4（可信度加权）
5. 人生/职业迷茫 → 用工具5（梦想+现实+决心）

记住：**原则不是读一遍就行，是要写下来、用起来。**
